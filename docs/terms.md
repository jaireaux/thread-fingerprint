# Terms of Service

Effective: September 19, 2026

Thread Fingerprint is provided as a read-only utility for creating a one-way fingerprint from conversation metadata supplied by a compatible host.

Thread Fingerprint Legacy Rescue is a separate skills-only workflow that creates a provisional NMCP label and handoff prompts without obtaining host metadata. An NMCP reference is user asserted and is not a fingerprint, validation, branch, or live connection between conversations.

The fingerprint is an observational correlator, not proof of authorship, ownership, identity, authenticity, permanence, or recoverability. Do not rely on it as the only record needed to locate or preserve a conversation.

Keep the original conversation until any copied handoff and new-conversation fingerprint have been checked. Legacy Rescue cannot guarantee that a conversation, handoff, or reference will remain available.
